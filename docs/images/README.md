# Captures d’écran

Placez dans ce dossier les captures d’écran réelles de l’application Sport Club Management.

Noms de fichiers conseillés :
- `accueil.png` — page d’accueil
- `liste-membres.png` — gestion des membres
- `swagger-api.png` — documentation Swagger

Une fois les images ajoutées, référencez-les dans le README principal avec des chemins relatifs, par exemple : `![Liste des membres](docs/images/liste-membres.png)`.
